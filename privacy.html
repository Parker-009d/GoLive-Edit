Privacy Policy

Effective date: November 4, 2026

GoLive Edit is a desktop audio mixer for Windows and macOS. This policy describes information the app handles and how its optional features use that information.

Audio and microphone

GoLive Edit accesses a microphone or audio-interface input only when you choose an input and start Local Live. Audio is processed on the computer running the app. If you start Local Recording, the app creates an audio file and saves it through the operating system's download flow. You choose where to keep or delete that file. GoLive Edit does not send microphone audio or recordings to GoLive.

Settings and audio devices

The app reads available audio-device names and supported formats so you can select an input and output. Mixer preferences, selected device identifiers, and related interface settings are stored in local app/browser storage on your computer. They are not sent to a GoLive account or cloud service.

OBS Control

If you use OBS Control, GoLive Edit connects to the OBS WebSocket address you configure. An optional OBS password you enter is used for that connection. The app does not transmit OBS connection details to GoLive.

Phone Remote Control

When you start Remote Control, GoLive Edit accepts a secure connection from a paired phone on your local Wi-Fi network or hotspot. Pairing uses a one-time code. The host stores trusted-device information and token hashes in local app data; the phone stores its pairing token in that browser's local storage. You can revoke a trusted device from GoLive Edit, and clearing the phone browser's site data removes its saved pairing.

The remote connection carries mixer commands, control values, live meter readings, and analyzer data so the phone and desktop stay synchronized. It does not carry raw audio. The connection is intended for your private local network; the host certificate is private and may trigger a browser trust warning. Use only the address shown in GoLive Edit on a network you trust, and do not enable router port forwarding for this feature.

Online services, advertising, and analytics

GoLive Edit does not require an account and does not include advertising or analytics features. The app has no GoLive-operated cloud audio service. Network connections occur only for features you choose, such as the OBS endpoint you configure or the local phone remote.

Your choices and data removal

You control when microphone capture, recording, OBS Control, and Phone Remote are used. Stop those features in the app when you are finished. Delete downloaded recordings using your operating system, remove paired devices in the app, and clear local app or browser data to remove saved preferences and pairings.

Children

GoLive Edit is a general-purpose audio tool and is not designed to collect information from children.

Policy changes and contact

This policy may be updated when GoLive Edit's features or data practices change. For privacy questions, contact the publisher through GoLive Edit support on GitHub. Do not post passwords, private recordings, or other sensitive information in a public issue.
